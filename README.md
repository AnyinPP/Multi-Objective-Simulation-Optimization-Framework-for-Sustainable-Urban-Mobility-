## Overview

This repository contains the source code and computational workflow for
a multi-objective simulation-optimization framework developed for
sustainable urban mobility planning.

The framework integrates microscopic traffic simulation with
mathematical optimization to evaluate and optimize transportation
systems under multiple, potentially conflicting objectives.

The framework was developed as part of research on simulation-based
planning of urban transportation systems, with an application to
Lagos, Nigeria.

## Research Objectives

The framework is designed to:

- evaluate alternative urban mobility strategies;
- quantify trade-offs between transportation objectives;
- integrate microscopic traffic simulation with optimization;
- support multimodal transportation planning;
- evaluate solutions using multiple sustainability-related indicators.

## Methodology

The computational framework consists of the following main components:

1. Transportation network representation
2. Traffic demand and scenario definition
3. Microscopic traffic simulation
4. Performance measurement
5. Multi-objective optimization
6. MILP-based analysis
7. Solution comparison and visualization
